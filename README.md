# 元气骑士 · 深渊回响

一款完全用原生 HTML5 Canvas + JavaScript 打造的《元气骑士》风格 Roguelike 地牢射击游戏。
**零依赖、零构建、零素材文件** —— 所有美术与音效都由代码程序化生成，双击 `index.html` 即可游玩。

---

## 快速开始

直接双击 `index.html`（或拖进浏览器）。无需服务器、无需联网。
推荐 Chrome / Edge / Firefox，建议全屏（F11）。

### 武器技能示例

每把武器右键释放专属技能，消耗能量并独立冷却：

- 霰弹枪 → **龙息弹**：喷出灼热烈焰，点燃敌人
- 狙击枪 → **洞穿射线**：贯穿全屏的电磁射线
- 加特林 → **旋风风暴**：原地旋转向四周狂射
- 黑洞发生器 → **奇点坍缩**：制造黑洞吸入并绞碎敌人
- 亡灵法杖 → **亡者军团**：召唤 3 名骷髅战士为你而战
- 巨剑 → **崩山击**：跃起猛砸，范围震荡并眩晕
- 龙牙剑 → **龙焰斩**：三重巨型龙焰剑气
- 混沌魔典 → **元素狂潮**：火/冰/雷/毒四元素同时爆发

| 贴脸压制 | 距离越近伤害越高，最高 +85% | 霰弹枪 |
| 远程精准 | 飞得越远伤害越高，最高 +90% | 狙击枪、高斯步枪 |

| 弹夹装填 | 打空需换弹，但每发伤害 +25% | 火箭筒、十字弩 |
| 碎裂弹 | 命中后炸开 3 枚碎片 | 榴弹、毒液枪、光棱枪 |

### 稀有度曲线

稀有度**始终单调递减**，越稀有越难拿到（算法层面强制约束）：

| 楼层 | 普通 | 精良 | 稀有 | 史诗 | 传说 |
|---|---|---|---|---|---|
| 1 | 61% | 28% | 8% | 1.9% | **0.3%** |
| 3 | 52% | 31% | 13% | 3.9% | **0.9%** |
| 6 | 37% | 34% | 20% | 7.1% | **1.8%** |

BOSS 宝箱有额外加成（传说约 2.4%→5.5%），"幸运"祝福也会提升上限。
各档位分别有 8 / 10 / 11 / 8 / 5 把武器，保证每档内部也足够多样。

### 关卡与房间

随机生成的房间图，包含：
- **战斗房**：进入即封锁大门，清空后开门（部分房间有第二波增援）
- **宝藏房 / 上锁黄金宝箱**：钥匙可在商店购买
- **商店**：出售武器、治疗、护甲、钥匙
- **祭坛**：献祭 15% 生命换取随机祝福
- **挑战房**：精英怪云集，通关必得稀有宝箱
- **BOSS 房**：三阶段 BOSS，击败后开启传送门 + 三选一祝福

### 战斗系统

生命 / 护甲（脱战自动恢复）/ 能量三条资源；暴击、击退、弹反、翻滚无敌帧；
燃烧、冰冻、中毒、感电、易伤五种状态；连锁闪电、黑洞牵引、陨石轰炸、
持续光束、地面领域（火海/毒雾/寒霜）等特效；屏幕震动、命中顿帧、动态光影与泛光。

## 新增功能（v5 四期版）

### 难度保底商店（困难/噩梦）
- 困难/噩梦难度下，**每层地图保证一个商店**，从三种中随机：
  - **武器商店**（weaponshop）：3 把武器
  - **消耗品商店**（consumableshop）：药水/护甲/钥匙
  - **配件商店**（partshop）：武器配件
- 简单/普通无保底（保持随机）

### 难度切换修复
- **大厅难度石碑**：E 键循环切换 4 级难度（原只有显示无法切换），实时持久化
- 修复种子 RNG 无参调用返回 NaN/恒 0 的隐患（`U.rng.rand/randi`、`U.rand/U.randi`），影响保底商店随机性

### 修复
- 拾取物（钱/心/能量/钥匙）磁吸时玩家翻滚远离不再飞出屏幕（负速度修复 + 磁吸取消 + 边界 clamp）

## 新增功能（v4 三期版）

### 拆解机（模块化拆解/重组）
- 地牢 `disassembler` 房 + 大厅设施：拆解武器 → 三个**独立部件**
  - **射弹类型**：弹道形态（ball/bolt/laser/arrow...）+ 连发数/散射
  - **武器属性**：伤害/射速/穿透/弹跳/追踪/元素等数值
  - **攻击方式**：type（gun/melee/laser...）+ 特性（trait）+ 依赖字段
- 部件可安装到**任意武器**（覆盖对应字段），跨类型改装（手枪→持续光束/挥砍）
- 安装时自动清除旧攻击方式残留字段；改装武器带标记
- 组合爆炸：48×47 = 2256 种拆解重组组合；部件随存档保存

### 修复
- **拾取物飞出屏幕**：磁吸速度在玩家远离时变负（d>97 时 120+(80-d)×7 < 0），钱被反向推出屏幕。
  修复：速度下限 0 + 玩家远离 160px 取消磁吸 + 地图边界 clamp，钱永不飞出。

## 新增功能（v3 二期版）

### 存档系统
- **自动存档**：每 30 秒 + 清空房间 + 换层 + 拾取武器时自动保存（localStorage）
- **手动存档**：暂停菜单"保存游戏"（3 个槽位），主菜单"继续冒险"/"读取存档"
- **崩溃恢复**：启动时检测自动存档，可一键继续
- 存档含完整武器快照（附魔/强化/配件）、祝福、楼层、已清房间、难度；地图用**种子重建**保证一致

### 4 级难度
设置面板可选：**简单（默认）/ 普通 / 困难 / 噩梦**。难度影响怪物血量/伤害/数量、奖励房数量、金币掉落、稀有度加成。

### 一大关两小关
6 大关 × 2 小关 = 12 小关：小关 1 普通地牢（关底守卫房），小关 2 BOSS 地牢。HUD 显示"第 N 大关 · M 小关"。

### 蓄力武器（4 把新武器）
蓄力狙击枪 / 蓄力法杖 / 蓄力重弩 / 蓄力战锤。蓄力条 HUD、满蓄力（第 3 段）特效与加成、切枪/翻滚中断蓄力。

### 纯直射激光武器（2 把新武器）
光子切割器（持续光束）/ 湮灭射线（粗光束 + 过热机制）。能量按秒消耗，HUD 过热条。

### 武器配件（改造）+ 武器商
6 种配件 × 3 级：精准瞄准镜/扩容弹夹/穿甲弹头/能量核心/爆裂模块/元素模块。每把武器 2 个配件槽，地牢 `gunsmith` 武器商房出售，大厅锻造台可改装。配件随武器快照存档。

### P2P 联机（SakuraFrp + WebRTC）
- `server/` 目录：本地信令服务器（`npm install && npm start`，端口 9000）
- 用 **SakuraFrp 创建 TCP 隧道**映射 9000 端口到公网
- 大厅"联机石碑"：主机创建房间（6 位房间码），客机输入服务器地址 + 房间码加入
- 主机权威同步：客机发输入（30Hz），主机广播快照（15Hz），客机快照渲染
- 引用开源库 `peerjs`（本地 `js/vendor/peerjs.min.js`），鲁棒性优先：心跳、断线提示、状态回调

### 修复
- **T0**：带属性（附魔/强化/配件）的武器掉落地面后属性不再丢失（`W.snapshot` 全链路保留）

## 新增功能（v2 检修版）

### 开局大厅
进入地牢前先在大厅准备：**英雄立牌**（E 切换 6 英雄）、**传送门**（E 开局）、
**锻造台**（合成/回收）、**扭蛋机**（30 金币抽武器）、**训练木桩**（攻击测试 DPS）、

### 合成与回收
- **合成台**（地牢 `forge` 房 / 大厅锻造台）：主武器（枪械/近战）+ 副武器（法杖/元素武器）
  → 合成新武器：**主武器形态 + 副武器元素属性**（如 `寒冰法杖 + 霰弹枪 → 霜寒·霰弹枪`）。
  无元素副武器则继承其弹道特性（追踪/穿透/弹跳）。伤害提升、稀有度取高（有概率 +1），消耗金币（材料可抵扣）。
- **回收机**（地牢 `recycle` 房）：分解武器 → 金币 + 材料点数。

## 开发者：自动化验证

```bash
node test/headless.js
```

会在 Node 中模拟 DOM 与 Canvas，自动：
1. 用 6 位英雄各跑一轮完整战斗；
2. 逐一装备全部 42 把武器并触发其技能；
3. 逐一生成全部 51 个怪物条目并驱动其 AI；
4. 从第 1 层一路打到第 6 层通关（遍历 57 个房间），全程检测角色是否被卡进实心格；
5. **门口卡死回归**：把角色摆在每扇门的 8 个不同位置走进未清理房间，验证封锁大门后不会被关在门框里。

其余测试：

```bash
node test/ui.js       # 菜单 → 图鉴 → 选人 → 开局 → 祝福 → 暂停 → 结算 → 重开
node test/traits.js   # 逐条验证 16 种武器特性"真的生效"（对比数值，而非仅不报错）
node test/rarity.js   # 打印各楼层稀有度掉落分布，确认单调递减
```

任何运行时异常都会被捕获并打印堆栈。

`tools/` 下另有基于 `@napi-rs/canvas` 的离线渲染脚本，可把真实游戏帧输出成 PNG
（`node tools/render.js`）并做画面亮度 / 色彩 / 素材完整性量化分析（`node tools/analyze2.js`）。

## 说明

- 全部美术为运行时程序化绘制，因此包体极小且分辨率无关。
- 音效与背景音乐由 WebAudio 振荡器实时合成，战斗激烈时音乐强度会自动提升。
- 设置中可关闭动态光影 / 屏幕震动 / 高密度粒子以适配低配设备。
